Data

Export or import your data as JSON files. Importing merges with existing data — duplicate IDs are skipped.

View import format

Import files must be JSON with one of these top-level shapes. The exportedAt field is optional.

Characters

{
  "exportedAt": "2025-05-02T12:00:00Z",  // optional
  "characters": [ { ...character}, ... ]
}

Custom Monsters

{
  "exportedAt": "2025-05-02T12:00:00Z",  // optional
  "monsters": [ { ...monster }, ... ]
}

The easiest way to get a valid file is to use the Export buttons above or the Export button on an individual character/monster form.
