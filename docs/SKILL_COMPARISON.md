# RuneQuest vs Dragonbane Skills Comparison

This document compares skills between RuneQuest: Roleplaying in Glorantha and Dragonbane (Free League's Year Zero Engine variant).

## Quick Reference

- ✅ **Direct Match** - Skills that are essentially the same
- ≈ **Similar** - Skills that cover similar ground but with differences
- 🔀 **Partial Overlap** - Skills that partially cover each other's scope
- ❌ **No Equivalent** - Skill exists in one system only

## System Philosophy Differences

### RuneQuest Approach:
- **Granular Combat**: Separate skills for each weapon type (Sword, Spear, Bow, etc.)
- **Split Perception**: Multiple perception skills (Listen, Scan, Search, Track)
- **Language Specialization**: Each language is a separate skill
- **Magic Diversity**: Three distinct magic systems (Spirit, Rune, Sorcery)
- **Cultural Skills**: Farming, cultural knowledge emphasized

### Dragonbane Approach:
- **Consolidated Combat**: Melee and Marksmanship cover all weapons
- **Unified Perception**: Single Awareness skill for all perception
- **Combined Languages**: One Languages skill covers all
- **Streamlined Magic**: Single magic system with different traditions
- **Social Focus**: Persuasion and Performance as separate skills
- **Versatile Acrobatics**: One skill for climbing, dodging, balance, and stunts

## Conversion Guidelines

### Converting RuneQuest Characters to Dragonbane:

**Combat Skills:**
- Use highest weapon skill → Melee or Marksmanship
- Dodge → Acrobatics

**Perception:**
- Average of Listen/Scan/Search → Awareness
- Track → Bushcraft

**Stealth:**
- Average of Hide/Move Quietly → Sneaking

**Knowledge:**
- Lore (Animal/Plant) → Bushcraft
- Lore (World) → Lore

**Physical:**
- Climb → Acrobatics

### Converting Dragonbane Characters to RuneQuest:

**Combat:**
- Melee → Split among weapon skills based on character concept
- Marksmanship → Bow or Sling (player's choice)
- Brawling → Unarmed

**Perception:**
- Awareness → Split among Listen, Scan, Search

**Stealth:**
- Sneaking → Both Hide and Move Quietly

**Physical:**
- Acrobatics → Both Climb and Dodge

## Skill Count Summary

- **RuneQuest:** ~30 skills (more granular)
- **Dragonbane:** ~18-20 skills (more streamlined)

RuneQuest emphasizes detailed simulation with separate skills for similar activities, while Dragonbane consolidates skills for faster play and broader applicability.
