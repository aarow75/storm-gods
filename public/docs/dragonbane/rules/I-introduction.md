# Chapter 1: In the Oldest Times

## Introduction

Welcome to Dragonbane, a tabletop role-playing game set in a world of fantasy adventure. This introduction provides an overview of the game and what you need to know to get started.

### What is Dragonbane?

Dragonbane is a fantasy role-playing game where players take on the roles of adventurers exploring a rich world filled with magic, monsters, and treasure.

### How to Use This Book

This guide contains all the rules and information needed to play Dragonbane. Whether you're a new player or an experienced game master, you'll find everything you need within these pages.

### What You Need to Play

To play Dragonbane, you will need:
- This rulebook
- Character sheets
- Dice (d20 for core rolls)
- Pen and paper for notes
