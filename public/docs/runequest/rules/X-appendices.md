## B. Success Levels and Outcomes

### D100 Roll Outcomes

| Outcome | Condition | Result |
|---|---|---|
| **Critical Success** | Roll ≤ 1/20 of skill | Best possible outcome |
| **Special Success** | Roll ≤ 1/5 of skill | Exceptional success |
| **Normal Success** | Roll ≤ skill rating | Standard success |
| **Failure** | Roll > skill rating | Action fails |
| **Fumble** | Roll 96–00 or ≤ 1/20 of failures | Worst possible outcome |

**Always Succeeds**: 01–05 on D100 (even if skill is lower)

**Always Fails**: 96–00 on D100 (even if skill is higher)

## C. Strike Rank Summary

### Base Strike Rank Calculation

```
Strike Rank = DEX Modifier + SIZ Modifier + Weapon Modifier + Other Adjustments
```

### Common Strike Rank Costs

| Action | Strike Ranks |
|---|---|
| Attack (melee) | 3–8 (varies by weapon) |
| Parry | 3 |
| Dodge | 3 |
| Cast Spirit Magic | 3–6 |
| Cast Rune Magic | 1 |
| Movement (3 meters) | +1 to SR |
| Multiple action | +3 to SR per additional action |

**Maximum per Round**: 12 total strike ranks available

## D. Encumbrance and Movement

## E. Combat Modifiers

### Attack Modifiers

| Situation | Modifier |
|---|---|
| Attacking unaware opponent | +40% to hit |
| Attacking helpless/immobilized | +40% to hit |
| Attacking prone target | +40% to hit |
| Attacking in darkness | –75% to hit |
| Attacking from prone | –50% to hit |
| Aimed blow (specific location) | Half skill, then apply modifiers |
| Multiple attacks (2nd+) | Cumulative –20% per action |

### Defense Modifiers

| Situation | Modifier |
|---|---|
| Parry (1st per round) | Normal chance |
| Parry (2nd+ per round) | Cumulative –20% |
| Dodge (1st per round) | Normal chance (unmodified even if prone) |
| Dodge (2nd+ per round) | Cumulative –20% |
| Large size opponent | –10% to dodge (for each size category) |
| Small size opponent | +10% to dodge (for each size category) |

### Damage Modifiers

| Situation | Modifier |
|---|---|
| Normal success | Roll normal damage |
| Special success (≤1/5 skill) | Double damage rolled |
| Critical success (≤1/20 skill) | Double maximum damage, ignore armor |
| Entangled/grappled | –20% attack, damage halved |
| Weapon vs. armor | Roll damage, subtract armor value |

### Spirit Magic Recovery

| Rest Method | Recovery Rate |
|---|---|
| Sleep/rest | 1 MP per 6 hours |
| Meditation (10 min) | +25% to casting chance (lasts 50 SR) |
| Ritual preparation (1 day) | +50% to casting chance (lasts 1 day) |

### Rune Point Recovery

| Method | Recovery |
|---|---|
| Holy day worship | Restore all RP (cult-specific day) |
| Ritual sacrifice | 1 RP per POW point sacrificed (permanent loss) |
| Artifact recharge | Variable (GM discretion) |

**Note**: Rune Points can only be replenished through holy day ceremonies or permanent sacrifice.

## G. Experience Improvement

### Skill Advancement

| Step | Action | Result |
|---|---|---|
| 1 | Use skill in adventure | Mark for experience roll |
| 2 | Roll D100 vs. current skill | Compare result |
| 3 | Roll ≥ current skill | Skill increases by 1D6% |
| 4 | Roll < current skill | No improvement; try next adventure |

**Maximum without training**: 95% (unless magical enhancement)

**Improvement attempt**: Retrying failed skill costs –20% penalty

## M. Characteristic Generation Methods

### Method 1: Roll 3D6

Standard rolling: Roll 3D6 for each characteristic, assign in order or as desired.

### Method 2: Characteristic Sets

Select from 6 pre-generated sets during character creation, each including:
- Characteristic values
- Rune affinities
- Skill category modifiers
- Associated passions

**Advantage**: Balanced options, thematic grouping

### When Two Abilities Oppose

| Outcome | Result |
|---|---|

## Summary of Key Formulas

### Character Mechanics

```
Total Hit Points = (CON + SIZ) ÷ 2
Damage Bonus = (STR + SIZ) table lookup
Healing Rate = CON ÷ 4
Strike Rank = DEX Mod + SIZ Mod + Weapon Mod + Adjustments
Magic Points = POW
Spirit Combat Damage = POW (direct value)
```

### Combat

```
Attack Roll = D100 vs. weapon skill
Damage = Weapon dice + damage bonus - armor
Success levels = Critical (≤1/20), Special (≤1/5), Normal (≤ skill), Failure, Fumble
```

### Magic

```
Spirit Magic = POW × 5 base chance, costs magic points
Rune Magic = Rune affinity %, costs rune points
```
